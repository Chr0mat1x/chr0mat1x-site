# Chr0mat1x

Лендинг студии разработки в чёрно-белом стиле: сайты, веб-приложения, Telegram-боты.

## Стек

- HTML5 + CSS3 + Vanilla JS (без фреймворков и сборки)
- Формы: Formspree
- Хостинг: GitHub Pages

## Структура

```
index.html      — страница (все секции)
css/style.css   — стили
js/script.js    — интерактив (меню, анимации, форма)
```

## Локальный запуск

```bash
python -m http.server 8000
```

Затем открыть http://127.0.0.1:8000/
